Why Does This Happen?

An 8-bit value only has 256 possible bit patterns. If a calculation produces a value outside the available range, only the lowest 8 bits are kept.

For example, storing 256 in an 8-bit unsigned integer produces 0, because the value wraps around after 255.

Signed integers use two's-complement representation. The bit pattern 10000000 represents 128 when interpreted as unsigned, but -128 when interpreted as signed.
