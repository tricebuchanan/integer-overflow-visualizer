# 8-Bit Integer Overflow Visualizer

This project is a small interactive web application that demonstrates how integer overflow works with 8-bit values.

The visualizer lets the user enter a number or move a slider and then shows how that value is stored using only 8 bits. It displays the binary bit pattern, the unsigned interpretation, the signed interpretation, and the hexadecimal value.

## Features

- Number input and slider controls
- Preset overflow examples
- 8-bit binary visualization
- Signed and unsigned interpretations
- Hexadecimal representation
- Overflow warning messages
- Explanation of 8-bit wraparound and two's-complement behavior

## How to Run

Open `index.html` in any modern web browser. No additional software or setup is required.

## Purpose

The goal of this project is to provide a simple teaching tool that makes integer overflow easier to understand by showing how values change when they exceed the range of an 8-bit integer.
